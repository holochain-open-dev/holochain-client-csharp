### HolochainHappGenerator (static class)

Generates a complete, buildable Holochain 0.7 hApp from a `HappSpec`: a Cargo workspace with an integrity zome (entry and link types, validation) and a coordinator zome per zome (create / get / update / delete for every entry, plus anchored collections), the dna.yaml and happ.yaml, a build script, and the matching C# HoloNET ORM models (a HoloNETEntryBase class per entry and a collection factory). The zome function shapes are the ones HoloNET ORM uses, so the generated models work against the generated hApp with no changes. Used by WEB5 STAR (via HoloOASIS) to generate hApps from metadata.

For this to work you need to make sure the 'ZomeBatchUpdateCollectionFunction' is set or was passed in via one of the constructors, it will then batch update any entries that have changed (added, removed or changed) since the last time this method was called. If 'saveAsOneBatchOperation' is set to false then it will call the SaveAsync method for updating each entry (if 'saveChangesMadeToEntries' is set to true), 'AddHoloNETEntryToCollectionAndSaveAsync' for adding new entries and 'RemoveHoloNETEntryFromCollectionAndSaveAsync' for removing old entries. This of course will be slower than updating them as a batch depending on the size of the collection. This will invoke the 'OnCollectionSaved' event once it has finished saving any changes to the collection. |
