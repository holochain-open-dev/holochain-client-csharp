HoloNET Sandbox

Try HoloNET with nothing to install. This page talks to a real Holochain conductor through the HoloNET API: save and load your own data, post to a board that every visitor shares, and run the API, Client, ORM and HyperNET demos.

Connecting to the sandbox...

The sandbox is shared and public: don't put anything private in it. Your keys disappear after 30 minutes idle, and the board keeps the latest 100 messages.

Each key is its own entry on Holochain, saved with HoloNETAPI.SaveDataAsync(key, value). Only you see these keys.

KeyValue

Nothing saved yet. Try the key greeting with the value Hello, Holochain!.

await HoloNETAPI.SaveDataAsync("greeting", "Hello, Holochain!");
string greeting = (await HoloNETAPI.LoadDataAsync("greeting")).Result;
await HoloNETAPI.DeleteDataAsync("greeting");

Shared data every agent can read and write, with HoloNETAPI.SaveSharedDataAsync(ns, key, value). Everyone using this page sees the same board.

One click runs the same demo that dotnet new holonet-... gives you, on the sandbox's conductor. The code is fixed: the page can't run anything else.
